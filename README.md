Retail Customer Analytics | SQL, Python & Power BI

Project Overview

This is an end-to-end Retail Customer Analytics project focused on analyzing retail transactions, customer behaviour, revenue performance, customer segmentation, RFM analysis, and churn.

The project uses SQL for data preparation and validation, Python for data cleaning, and Power BI for interactive dashboard development.

Tools & Technologies

- PostgreSQL – Data storage, SQL queries and data validation
- Python – Data cleaning and preparation
- Pandas & NumPy – Data manipulation
- Power BI – Interactive dashboards and visualizations
- Jupyter Notebook – Python analysis
- VS Code & pgAdmin 4

Project Workflow

1. SQL Data Preparation

- Created separate tables for two retail datasets (2009–2010 and 2010–2011).
- Combined both datasets using UNION ALL.
- Converted invoice date values into timestamp format.
- Checked missing customer IDs and descriptions.
- Identified non-positive quantities.
- Detected and removed exact duplicate records.

2. Python Data Cleaning

- Used Python and Pandas for data cleaning and preparation.
- Used NumPy for data manipulation.
- Prepared data for further analysis and visualization.

3. Power BI Dashboard

The dashboard contains three pages:

Home Page

- Business Overview
- RFM Analysis introduction
- Key Metrics Glossary

Business Overview

- Total Customers
- Total Revenue
- Churned Percentage
- Average Customer Value
- Revenue by Customer Segment
- Revenue by Month, Quarter and Year
- Revenue Retention by Segment

RFM Analysis

- Country Performance Summary
- Top 5 Countries by Average Customer Value
- Monthly Churn Analysis
- Quarterly Churn Analysis
- Yearly Churn Analysis
- Segment and Country selection

Key Business Metrics

- Recency (R): How recently a customer made a purchase.
- Frequency (F): How often a customer makes purchases.
- Monetary (M): How much value a customer generates.
- Churn Rate: Percentage of customers who have stopped purchasing.
- Customer Value: Average revenue generated per customer.
